# virtual-exhibition
Hosted on:
https://virtual-exhibtion-ia.netlify.app/

This project is a website for creating virtual exhibitions from artworks/artefacts in museum databases. The current museum databases used are the Science Museum Group and the Victoria and Albert Museum collection.

To run project locally

Fork the github repo and clone the forked repo to your device. 
All dependencies are included in the package.json: use "npm install" to download dependencies. 
Use "npm run dev" to run the project locally.

Versions used: 
    Node.js: v24.6.0
    React.js: 19.1.16
